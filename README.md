# الباك إند (API + الداتا بيز)

الملفات: `server.js` و`package.json` و`.env` (الإعدادات).

## التشغيل
1. ملف `.env` جاهز. `DATABASE_URL` فاضي عن قصد، فالسيرفر هيعمل داتا بيز محلية على جهازك جوه مجلد `data`.
2. في الـ Terminal من داخل المجلد:
   ```
   npm install
   npm start
   ```
3. لو اشتغل هتلاقي: `السيرفر (الباك إند) شغال على http://localhost:3000`

الجداول بتتعمل تلقائيًا أول تشغيل. بعد أي تعديل في `.env` اعمل إعادة تشغيل للسيرفر.

## عند النشر
لازم داتا بيز PostgreSQL أونلاين (زي neon.tech)، وحط رابطها في `DATABASE_URL`. ضيف نفس القيم في Environment Variables في الاستضافة، وخلي `ALLOWED_ORIGIN` رابط الفرونت إند بتاعك.
